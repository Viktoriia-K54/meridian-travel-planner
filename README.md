# MERIDIAN — ателье путешествий

Интерактивный планировщик путешествий: опросник из 13 вопросов, подборка из 3–5 направлений и полный разбор выбранного маршрута — по дням, с бюджетом, логистикой, чек-листом бронирований и списком вещей. В каталоге 29 направлений: Россия, Кавказ и несколько зарубежных маршрутов.

Проект работает целиком в браузере, без сборки и без сервера.

## Запуск

1. Откройте `index.html` двойным щелчком.
2. Либо запустите локальный сервер из папки проекта:

```bash
python -m http.server 8080
```

и откройте `http://localhost:8080`.

Всё приложение — на классических скриптах, поэтому `file://` тоже работает. Интернет нужен только для шрифтов Google Fonts; без него включаются системные запасные шрифты, а фотографии остаются локальными.

**Браузеры:** актуальные Chrome, Edge, Firefox, Safari.

## Как устроен сценарий

1. **Главный экран** — короткое объяснение и старт.
2. **13 вопросов** — по одному на экран, с прогрессом и возвратом. Первый вопрос — про страну: можно выбрать конкретную страну или попросить свободный подбор.
3. **Профиль путешественника** — проверка вводных, любой блок можно изменить. Здесь же — история прошлых поездок: место и маршрут, который можно добавить вручную.
4. **Подборка** — 3–5 направлений: страна/место, тип отдыха, сложность, длительность, бюджет, процент совпадения и честные оговорки.
5. **Детальный маршрут** — дни, бюджет по статьям, логистика, районы проживания, чек-лист бронирований (отметки сохраняются), вещи, риски.
6. **Выбор варианта** — выбранное направление отмечается в подборке; маршрут можно распечатать или сохранить в PDF через печать браузера.

Состояние сохраняется в `localStorage` (ключ `meridian.travel.v1`). Если хранилище недоступно, приложение продолжает работать в памяти вкладки.

## Почему 13 вопросов

13 вопросов — оптимум между полнотой вводных и усталостью от анкеты. Первый блок — контекстный, в нём четыре вопроса; остальные блоки по три:

| Блок | Вопросы | Что выясняем |
| --- | --- | --- |
| Контекст | 1–4 | Страна, с кем едем, когда, на сколько дней |
| Бюджет и формат | 5–7 | Потолок бюджета, форматы отдыха, темп |
| Комфорт и логистика | 8–10 | Отель и класс перелёта, пересадки, виза |
| Вы и желания | 11–13 | Климат, три акцента, ограничения и мечта |

Дальше добавлять вопросы невыгодно: они почти не меняют подбор, но заметно удлиняют анкету. Всё критичное для логики уже покрыто.

## Жёсткие и гибкие параметры

Ключевая идея: пользователь сам решает, что является ограничением, а что — пожеланием.

| Параметр | Жёстко | Гибко |
| --- | --- | --- |
| Даты | Точные даты (опционально ±3 дня) | Сезон или полная свобода |
| Длительность | Фиксированное число дней | ±2 дня |
| Бюджет | Жёсткий потолок | Можно +15% |
| Темп | Принципиален | Допустим один шаг в сторону |
| Комфорт | Важен | Можно варьировать |
| Пересадки | Только прямой рейс | Можно стыковку |
| Виза | Всегда жёсткое ограничение | — |

Виза не имеет гибкого режима намеренно: обещать «почти безвизовое» направление было бы нечестно.

## География каталога

- **Россия — 17 направлений:** Алтай, Камчатка, Сахалин, Мурманск, Дагестан, Соловки, Карелия, Байкал, Калининград, Сочи, Кавказские Минеральные Воды, Приэльбрусье, Домбай и Архыз, Северная Осетия, Чечня, Ингушетия, Адыгея.
- **Кавказ целиком:** российский Северный Кавказ (9 направлений), Грузия, Армения и Азербайджан.
- **Остальное:** Турция, Италия, Исландия, Марокко, Таиланд, Португалия, Норвегия, Япония, Шри-Ланка.

Каждое направление имеет собственный маршрут по дням, бюджет, логистику, чек-лист и риски. Регионы Северного Кавказа описаны нейтрально; часть объектов находится в приграничных зонах, поэтому перед поездкой нужно проверять актуальные правила.

## Логика подбора

1. **Страна** — жёсткий фильтр. Если выбрана конкретная страна, каталог сужается до неё ещё до скоринга; мягкий режим тоже не выходит за её пределы.
2. **Жёсткие фильтры** отсекают направления, которые нарушают обязательные условия: виза, бюджет, фиксированная длительность, прямой рейс, поездка с детьми при высокой сложности.
3. **Взвешенный скоринг** оценивает совпадение: формат отдыха (до 42 баллов), бюджет, сезон, темп, климат, перелёт, комфорт, акценты, компанию.
4. **История поездок** — мягкое ограничение. Места и маршруты, которые пользователь добавил в профиль, получают штраф и не показываются, если есть хотя бы три свежие альтернативы. Если свежих вариантов меньше, они возвращаются в подборку со значком «Вы уже были».
5. **Мягкий режим** включается, только если строгих совпадений меньше трёх: границы бюджета расширяются, а неподходящие варианты честно помечаются значком «Ближайший вариант».
6. **Пятый вариант** со значком «Свежий взгляд» — намеренно другое направление по типу отдыха. Это попытка показать неочевидную альтернативу, а не ошибка подбора.

Процент совпадения — не рейтинг стран, а объяснение, насколько направление отвечает вводным. Он ограничен диапазоном 52–98%, чтобы не создавать ложного впечатления абсолютной точности.

## Важно про данные

- Бюджеты — **ориентировочные оценки** в рублях на человека при двухместном размещении. Они не являются офертой.
- Сезоны, визовые правила, длительность перелётов и цены меняются. Перед бронированием их нужно проверять.
- Для одноместной поездки к бюджету стоит добавить 15–25%.
- Шопинг, визовые сборы и личные траты в оценку не включены.
- Все оговорки продублированы в интерфейсе.

## Проверки

```bash
node scripts/smoke_test.js
node scripts/e2e_test.js
```

`smoke_test.js` проверяет целостность каталога (29 направлений и 29 маршрутов, включая Кавказ), работу подбора на пяти профилях, фильтр по стране, историю поездок и рендер всех экранов. `e2e_test.js` проходит сценарий в настоящем браузере: 13 вопросов → профиль с историей поездок → подборка → детальный маршрут → чек-лист → выбор варианта.

## Технические решения

- **Без фреймворков и сборки.** Классические скрипты, один HTML-файл, четыре CSS-файла.
- **Иммутабельное состояние.** Ответы и результаты не мутируются, а заменяются новыми объектами.
- **Безопасный вывод.** Пользовательский текст экранируется; данные каталога считаются доверенными.
- **Доступность.** Семантические кнопки, `aria-pressed`/`aria-checked`, видимый фокус, поддержка клавиатуры (←/→ в опроснике), `prefers-reduced-motion`.
- **Печать.** Отдельные стили убирают навигацию и боковую панель, оставляя читаемый маршрут.
